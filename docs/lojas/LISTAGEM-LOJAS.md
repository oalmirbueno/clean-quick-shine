## Privacidade do app (Apple → App Privacy)

**Coleta dados?** Sim. **Usa para rastreamento (tracking)?** Não. Nenhum dado é
usado para publicidade nem cruzado com dados de outras empresas.

Todos abaixo: **vinculados ao usuário**, **não** usados para rastreamento,
finalidade **Funcionalidade do app** (e Atendimento ao cliente onde indicado).

| Tipo (Apple) | Item | Por quê |
|---|---|---|
| Informações de contato | Nome | conta e pedido |
| Informações de contato | E-mail | login e avisos |
| Informações de contato | Telefone | contato da diarista e do suporte |
| Informações de contato | Endereço físico | local da limpeza |
| Localização | Localização precisa | achar diaristas perto e mostrar a chegada |
| Informações financeiras | Informações de pagamento | cobrança do serviço (processada pelo Asaas) |
| Informações financeiras | Outras informações financeiras | chave Pix e dados bancários da diarista para saque |
| Conteúdo do usuário | Fotos ou vídeos | foto de perfil, anexo no chat, documentos da diarista |
| Conteúdo do usuário | Atendimento ao cliente | chamados e denúncias |
| Conteúdo do usuário | Outro conteúdo do usuário | mensagens do chat e avaliações |
| Identificadores | ID do usuário | conta |
| Identificadores | ID do aparelho | token de notificação push |
| Outros dados | Outros tipos de dados | CPF, exigido para emitir a cobrança |

Não coleta: saúde, contatos da agenda, histórico de navegação, histórico de
busca, dados de uso para análise, diagnóstico de terceiros.

## Segurança dos dados (Google Play → Data safety)

- **O app coleta ou compartilha dados?** Sim.
- **Os dados são criptografados em trânsito?** Sim.
- **O usuário pode pedir a exclusão?** Sim, no app (Perfil → Excluir minha
  conta) e em https://jalimpo.com/account-deletion.
- **Compartilhamento:** marque **não compartilha**. Os envios para o Asaas
  (processador de pagamento) e para o Firebase/Apple (entrega de push) são feitos
  por prestadores de serviço em nome do app. A troca de dados entre cliente e
  diarista dentro do pedido é iniciada pelo próprio usuário. As duas situações
  ficam fora do que o Google considera "compartilhamento".

Coletados (todos **obrigatórios** e com finalidade **Funcionalidade do app** +
**Gerenciamento da conta**; nenhum para publicidade ou análise):

| Categoria | Tipo |
|---|---|
| Local | Local aproximado · Local exato |
| Informações pessoais | Nome · Endereço de e-mail · IDs do usuário · Endereço · Número de telefone · Outras informações (CPF) |
| Informações financeiras | Informações de pagamento do usuário |
| Mensagens | Outras mensagens no app (chat) |
| Fotos e vídeos | Fotos (opcional) |
| Arquivos e documentos | Arquivos e documentos (documentos da diarista) |
| IDs de dispositivo ou outros | IDs de dispositivo ou outros (token push) |
